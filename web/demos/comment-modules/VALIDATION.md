后续根据批注增加模块全选后的评论折叠箭头，位于复选框前。15 项 React 测试验证部分选择时隐藏入口、混合状态统一折叠、模块外选区保留、筛选与视觉隐藏成员、正文规则排除全部结构标题、保存失败和模拟撤销。浏览器检查补充键盘批量切换、模块隐藏时操作、模拟快照与撤销，并在窄屏触屏条件下检查箭头的可点击尺寸和切换结果。该阶段未接入正式 MarginNote 评论保存。

## 已知限制与待验收内容

- Chromium 触屏模拟不能替代真实 iPad 验收。真实设备上的滚动接管、捏合冲突及 MarginNote 宿主手势尚未验证。
- 浏览器已接管触摸或仍处于滚动惯性时，无法可靠取消默认行为。演示会拒绝开始多选并显示重新落指提示。
- 多选手势接管后发生捏合，选区恢复；系统缩放需要抬手后重新开始。演示未禁用浏览器缩放。
- 真实评论标识、原生保存、宿主撤销和跨卡片引用同步留待正式接入阶段验收。
- 构建包含复用的内容渲染器与 KaTeX，Vite 提示 JavaScript 分块超过 500 KB；独立演示构建与功能检查通过。
