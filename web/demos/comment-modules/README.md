# 评论模块与双指多选演示

该演示沿用评论管理器的顶栏、模块目录、评论列表和固定底栏，复用现有样式、Markdown 渲染器与单条评论折叠组件。演示使用独立入口和模拟 Bridge，所有内容操作仅处理样例数据。

## 构建与启动

在仓库根目录运行以下命令。构建只生成独立演示，不运行插件自动部署，不生成安装包。

```sh
node web/demos/comment-modules/build.mjs
node dist/comment-modules-demo/start.mjs
```

浏览器访问 [本地演示](http://127.0.0.1:5187)。页面需要通过本地服务打开，直接打开 HTML 文件无法访问模拟存储。

构建目录包含网页资源、预览服务和启动说明。整个目录可复制到其他位置，通过 `node start.mjs` 启动。预览服务只依赖 Node.js 内置模块；运行环境需要支持 `structuredClone`，建议使用 Node.js 20 或更新版本。

默认模拟数据文件为构建目录旁的 `comment-modules-state.json`，重新构建网页不会清除该文件。服务采用原子替换保存，损坏的 JSON 会导致启动失败并保留原文件。配置和内容保存失败时，页面保留操作草稿并显示错误。

以下环境变量用于指定端口、存储路径或输出目录。输出目录应专用于演示构建，构建会替换目录中的旧资源。

```sh
MN_MODULE_DEMO_PORT=5190 node dist/comment-modules-demo/start.mjs
MN_MODULE_DEMO_STORE=/tmp/mn-module-demo-state.json node dist/comment-modules-demo/start.mjs
MN_MODULE_DEMO_OUTPUT=/tmp/mn-module-demo node web/demos/comment-modules/build.mjs
```

## 功能与使用方式

- 顶栏的卡片下拉框切换混合评论、Markdown 章节、指定文本、空卡片和长列表样例；提取后的子卡片也会加入列表。
- 顶栏的设置按钮配置全局默认或当前卡片覆盖。方案支持 HTML、Markdown、HTML＋Markdown 和指定文本划分；方案可重命名或复制，再调整匹配条件和标题级别。
- 配置默认选择当前卡片覆盖。方案规则属于共享配置，修改已有方案会影响使用该方案的卡片；复制方案可以保留原有规则。正文划分不拆分单条评论。
- 模块边界根据完整评论顺序计算。搜索只过滤显示内容；父级模块选择包含子级，模块复选框包含隐藏成员。
- 模块选择默认包含标题。配置可以排除当前模块及子模块的结构标题；模块菜单还提供完整模块、仅正文及当前标题的临时选择入口。
- 模块头使用没有可见文字和边框的文件夹图标按钮，只控制整组内容的显示；“隐藏模块内容／显示模块内容”保留在悬停提示与无障碍名称中。隐藏后的提示明确保留评论的全文或摘要状态。单条评论左侧的箭头按钮切换全文与摘要，底栏按钮处理所选评论；模块内容显隐属于临时界面状态。
- 模块按当前标题选择规则全选后，复选框前显示评论折叠箭头。该箭头批量切换该模块所选评论的全文与摘要，包含筛选隐藏成员及子模块，其他模块的选区不受影响。全部评论已折叠时统一展开，否则统一折叠；部分选中或没有可选成员时不显示该入口。模块内容隐藏后仍可操作，保存失败保留选区，模拟撤销可恢复评论状态。
- 模块头的上下按钮调整同父级、同标题级别模块的顺序。窄屏隐藏上下按钮，模块菜单仍提供整体移动入口。移动始终包含结构标题与子模块。
- 底栏提供正文移动和子卡片提取。正文移动保留原有顺序，拒绝结构标题及当前所属模块；子卡片提取默认保留源内容，移除源内容需要勾选对应选项。
- 顶栏撤销按钮恢复模拟内容或配置。重置操作需要确认，并且可以撤销。保存的撤销历史最多保留最近 40 次操作。
- 模块收起状态与选区只在当前页面中保留。方案、单卡片覆盖、模拟评论折叠、模拟内容及撤销历史通过服务端 JSON 保存，页面刷新后可恢复。

## 双指多选

单指继续滚动。双指落在评论正文、正文普通链接或评论之间的窄间隙时可以开始候选手势。共同纵向位移达到 8 像素、方向具有纵向意图且共同运动大于相对运动时开始多选；轻微斜向起步可以继续判定。起点未选时增加选择，起点已选时取消选择；范围之外的已有选区保持不变，反向滑动允许回缩。移动按动画帧合并，抬起手指时处理尚未执行的最后位置并保留选区。

双指手势仅处理当前渲染的评论，不包含筛选隐藏项或收起模块内部的评论。模块标题不是整组选择的手势入口，按钮、链接和输入控件不作为手势起点。接近列表上下边缘 36 像素区域时自动滚动。

识别前的明确捏合不会进入多选；已经识别为多选后，间距变化不再切换手势类别。额外触点、系统触摸取消、卡片切换或弹窗打开按照对应规则终止手势；普通中断恢复开始前的选区，卡片切换保留新卡片的选区。检测到浏览器已经接管滚动时，手势不会写入选区，并提示抬手后同时放下双指。

双指识别需要取消当前触摸的默认行为。捏合取消多选后，当前触摸不能直接恢复系统缩放，应抬手后重新缩放。页面未关闭浏览器的缩放能力。

底栏“选范围”保留原有连续选择语义，包含起点与终点之间的隐藏评论；该入口与双指仅选择显示项的语义不同。

## 验证命令

以下命令在仓库根目录运行：

```sh
node --test web/demos/comment-modules/test-engine.mjs web/demos/comment-modules/test-gesture.mjs web/demos/comment-modules/test-store.mjs
node node_modules/vitest/vitest.mjs run --config web/demos/comment-modules/vitest.config.mjs
node web/demos/comment-modules/build.mjs
node web/demos/comment-modules/check-browser.mjs
```

浏览器检查需要可用的 Playwright 和 Chromium。脚本使用隔离浏览器及临时样例存储，测试不会修改正在使用的演示数据。环境已有独立 Playwright 安装时，可以设置 `MN_MODULE_DEMO_PLAYWRIGHT` 为对应包目录；`MN_MODULE_DEMO_CHROME` 可以指定 Chromium 可执行文件。

浏览器检查结果默认保存在仓库的 `dist/comment-modules-checks/`，包含 JSON 报告及桌面、窄屏和触屏截图。测试代码分别覆盖规则计算、模拟事务、保存恢复、选择交互和浏览器多点触摸。

## iPad 与宿主验收

默认预览服务仅监听本机。进行 iPad 测试时，在受信任的局域网中运行以下命令，并通过电脑的局域网地址访问对应端口。服务仍只提供演示页面和模拟数据。

```sh
MN_MODULE_DEMO_HOST=0.0.0.0 node dist/comment-modules-demo/start.mjs
```

真机验收应包含单指滚动、双指增选、双指取消选择、反向回缩、边缘自动滚动、捏合取消、额外触点、弹窗中断，以及搜索和收起模块后的选择范围。

Chromium 触屏模拟只能证明模拟环境中的事件行为。真实 iPad 多点触摸、MarginNote 宿主手势、原生评论标识、真实保存与撤销仍需单独验收。演示没有接入 MarginNote 资料库，也没有发布插件版本。
