# 原生富文本生命周期原型

原型复用正式评论管理器的布局和评论预览，使用独立示例数据。打开构建后的 HTML 即可测试，无需启动服务。页面不连接 MarginNote，不读写真实评论，也不访问系统剪贴板；刷新页面会重置全部示例。

[打开完整原型](../../../artifacts/rich-text-lifecycle-prototype/index.html)

## 操作流程

- 点击 HTML 标签旁的复制图标保存格式快照，操作结束后不会打开目标列表。切换至“定义卡”后，可以通过目标评论旁的粘贴图标单独操作，也可以通过顶部“批量粘贴”多选目标。
- 点击画刷图标进入一次性格式刷，直接使用当前评论的样式，只列出当前卡片的其他 HTML 评论。应用后退出；取消、应用和撤销均不读取或改写已复制格式。格式刷与跨卡片复制／粘贴分别维护来源和操作记录。
- 粘贴预览并排显示当前内容与应用结果。HTML 保留正文；普通文字和简单 Markdown 转换为原生 HTML 类型。Markdown 使用显示文字，移除语法标记；图片、公式、表格、链接、嵌套列表及其他复杂结构禁止转换，并显示原因。
- 点击铅笔图标或双击 HTML 正文可打开编辑器。编辑器支持正文、换行、字号、字重、自定义文字色和背景色；颜色可使用取色器或 `#RRGGBB` 输入，也可恢复默认文字色或透明背景。草稿只影响预览，保存后列表立即更新。
- “新增”可以在空白卡片创建富文本；已有复制格式时，新评论采用该格式。
- 顶部撤销图标恢复当前卡片最近一次修改。批量粘贴作为整次操作撤销，恢复原评论类型、原始 Markdown、正文、格式、顺序和元数据。卡片切换保留各卡片的撤销历史，复制格式不会覆盖撤销历史。
- 取消或按 Esc 放弃未保存的预览和草稿。关闭对话框后焦点返回操作入口；保存期间禁止重复提交。右上角重置图标恢复全部示例。

## 范围

本次修订接入工作区刚更新的“评论线框”共享图标，管理器、画刷、编辑、新增、关闭和重置采用相应新图标。图标包尚未覆盖复制、粘贴和撤销，相关操作保留标准图形并统一笔画。窄屏优先显示富文本操作，移动与删除继续通过已有“更多”入口使用。

原型演示整条评论的统一样式。混合格式和含受保护元数据的目标禁止覆盖。逐字样式、下划线、竖条等 C/D 组方案继续沿用现有能力核验结论，不在本次原型中新增原生能力声明。

正式界面的筛选、选择和模块展示继续复用现有组件。与富文本流程无关的原生命令未接入模拟接口。原型保存与刷新只验证网页交互，不构成 MarginNote 原生保存、双击编辑、卡片重绘或系统撤销的实机证据。

```sh

MN_PUPPETEER_MODULE=/Users/xiakangwei/node_modules/puppeteer \
```
