# 手写解析回归样本

该目录保存按字段结构构造的合成样本，不包含真实用户笔迹，也不代表设备验收通过。

- `handwriting.js` 构造带版本字段、完整笔刷、颜色、通道布局及坐标变换的裸 `wrd`。
- `handwriting-archives.json` 使用 Python 标准库 `plistlib` 构造直接字典、`NSKeyedArchiver`、单绘图和冲突归档。
- 基准笔画的原始坐标为 `(1, 2)`、`(3, 4)`，平移量为 `(10, 20)`，笔宽为 `3`；预期坐标为 `(11, 22)`、`(13, 24)`。测试直接断言预期值，不使用生产解析器计算预期结果。
- 回归覆盖通道标志、公共与逐点笔宽、透明度、坐标变换、归档一致性、受限预览、文字识别及导出限制、截断与非法数据。

真实裸绘图、归档、图片叠加手写、不同笔刷及擦除后的样本仍需经授权取得并分别验收；当前没有以合成样本代替真实笔迹还原结论。
