# 模块化正式接入需求说明

日期：2026-10-11。依据已批准的独立演示计划、演示批注和正式开发授权；根据最新批注追加双指滑动接入，真实设备验收留待后续。

## 问题与成功标准

正式面板目前提供 HTML 字段定位，评论列表仍然平铺。模块划分需要支持 HTML、Markdown、HtmlMD、嵌套及指定文本规则，并保持完整评论顺序、筛选选择与原有编辑能力。

成功标准为当前卡片面板能够保存和恢复全局默认及单卡片覆盖，呈现模块层级、未分组内容、空模块与重复标题，完成模块显隐、定位、整组选择、同级移动、正文移动与提取。模块全选后显示评论折叠箭头，并调用现有宿主折叠接口。

## 范围与约束

- 本阶段接入当前卡片面板。多卡片工作流继续沿用既有能力，模块选择器扩展留待后续规划。
- 双指滑动接入正式当前卡片面板，只处理筛选和模块显隐后实际呈现的评论，原生摘录与模块容器标题不参与手势选择。单指保持滚动；双指中心纵向位移达到 12 像素且超过横向位移后开始选择，起点状态决定增选或取消选择，反向滑动依据初始选区回缩。
- 列表边缘 36 像素区域自动滚动。捏合、额外触点、系统取消、卡片切换、列表变化或弹窗打开时中断手势；原有卡片的取消恢复开始前选区，卡片切换不把旧卡片选区写入新卡片。抬手保留已完成选区。
- 双指先使用独立演示中已有实现，抽取为共用网页手势模块；自动测试与浏览器模拟检查不能替代真实 iPad 和 MarginNote 验收，连接排障仍暂缓。
- 默认采用 HTML 标题划分、模块展开、选择包含标题；单卡片覆盖优先于全局默认。
- 模块边界先于筛选计算。父级选择包含子级与隐藏成员，正文选择排除全部结构标题。
- 文件夹仅控制当前页面的内容显隐；评论折叠箭头控制该模块所选评论的全文与摘要，混合状态先统一折叠。
- 原生摘录位于评论列表上方，不属于评论模块。结构标题仍保留原有评论编辑、复制及删除入口，单条评论不拆分。
- 配置由插件层保存到独立 JSON 文件，禁止网页持久化业务数据。修改配置和移动模块前校验配置版本及评论结构，失败保护原文件与界面草稿。
- 保护现有折叠与工作流修复。本阶段不提交、推送或发版，不改写仓库的构建资源。

## 初步方案

提取纯规则模块，前端用于分组与选择，生成对应的 JavaScriptCore 脚本用于操作范围校验。模块配置增加独立 Bridge 命令，采用现有 NSJSONSerialization、原子文件写入及回读校验模式。

面板增加独立模块容器和配置窗口，复用现有评论渲染与折叠接口。模块移动和正文移动复用评论移动实现，提取复用子卡片生成实现；原生操作仍由既有撤销与刷新流程负责。

## 待验收内容

自动测试验证规则、Native 配置模拟、Bridge 范围校验、设置草稿、筛选隐藏成员、标题规则及既有交互回归。正式页面完成隔离构建和浏览器布局检查。真实 MarginNote 配置恢复、保存、引用卡、撤销与重做仍需宿主验收。
