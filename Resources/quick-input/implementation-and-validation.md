# 轻量评论输入接入与验证

日期：2026-10-12。状态：源码与模拟验证完成，真实 MarginNote 验收待完成。

本次数据处理审查已完成修复，最新测试与测试包见 [审查与验证记录](review-and-validation.md)。下述 180 项测试及 preview 测试包属于此前接入阶段的证据。

## 已确认的行为

用户确认双图标浮动入口，并允许分别配置单击和长按动作。管理按钮默认单击打开评论管理器、长按打开单卡片处理菜单；添加按钮默认单击打开快速输入、长按打开处理菜单。设置允许隐藏添加按钮，原有单卡片按钮开关继续控制整组显示。

快速输入只追加纯文本评论，保持原有内容及正文中的空白、换行。普通回车提交，Shift＋回车换行；软件键盘的换行输入事件也纳入提交处理。中文选词期间不提交。输入框提供换行、提交和关闭图标。

关闭时，正文保留在当前窗口的原生会话内，再次打开同一卡片可以恢复。应用重启、窗口断开及笔记本切换会清除会话；该草稿不承担长期持久化功能。点击背景不丢弃非空正文。

## 技术实现

快速输入使用独立透明 WebView 和独立 React 构建入口，不加载完整评论管理器、Markdown 渲染器或公式资源。正式资源由 `scripts/web-build.js` 生成；源码位于 `web/`，未手工修改 `src/web-dist/`。

网页通过共享 MNBridge 发送 `getQuickCommentState`、`updateQuickCommentDraft`、`appendQuickComment` 和 `closeQuickComment`。原生控制器只接受该窗口的命令，提交时核对会话标识；目标卡片在打开时固定，不依赖后续焦点或 Dynamic 菜单状态。

原生追加在撤销组中调用 `appendTextComment`，随后调用 `Database.sharedInstance().savedb()` 并回读新增文本。接口依据项目 Frameworks 的 `JSBMbModelTool.h`、既有修改流程及 MarginNote 文档核实。保存回执表示保存调用与文本回读均通过；真实设备重开、重启恢复仍需验收，不能仅根据模拟测试宣称磁盘持久化已获验证。

重复提交标识返回已有结果。写入前失败允许重新提交；可能已经追加的异常进入待核对状态，只重新保存并回读，不再次追加。窗口关闭时禁止后续追加，关闭回执先于 WebView 移除返回。保存后的刷新或动画异常不触发重复写入。

按钮动作通过带插件前缀的 NSUserDefaults 保存；网页不使用浏览器存储保存业务数据。原生会话按插件窗口隔离。

## 界面与动画

首版采用已接受的半透明遮罩、圆角输入面板、细边框和柔和阴影。当前公开插件接口未提供经过验证的整屏真实模糊方案，网页样式中的模糊效果不作为原生背景模糊的证明。

手机面板显示在可见区域底部，其他尺寸居中，最大宽度为 560 像素。VisualViewport 变化控制键盘避让；提交成功后固定动画起始布局，避免键盘收起改变移动轨迹。

打开动画约 180 毫秒。确认保存后，正文约 120 毫秒淡出，面板随后缩小并沿短弧线移向目标卡片，整体约 480 毫秒。目标优先使用可见脑图节点，其次使用尚未失效的入口区域；区域不可用时只淡出。减少动态效果时只使用约 120 毫秒淡出。
