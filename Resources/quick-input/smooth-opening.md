# 平缓入场与页面就绪

日期：2026-10-12。用户确认原生渐隐版的退场明显改善，并反馈打开时白底突然出现。

## 改动

原生覆盖层在加入宿主视图之前设置为透明。前端恢复正文、草稿与类型并完成首轮渲染后，通过 presentQuickComment 请求显示；原生覆盖层采用约 300 毫秒的 ease-in-out 淡入。网页背景和输入框从页面就绪时开始同长度入场动画，避免加载期间先显示空白面板。减少动态效果时仅采用 120 毫秒淡入，不执行上移动画。

原生层在透明度模型允许后重试聚焦。重复的显示请求只启动一次动画；迟到的就绪通知不能中断退场或关闭。网页加载完成后设置 800 毫秒的显示兜底，动画接口异常时直接恢复可见状态，避免窗口永久不可见。兜底不改变保存、评论或草稿数据。
