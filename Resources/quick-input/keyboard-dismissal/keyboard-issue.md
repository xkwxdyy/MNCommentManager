## 问题描述

用户反馈：iPad 或 iPhone 点击系统键盘右下角的收起按钮后，快速输入框仍显示。预期输入框随键盘关闭，最好同时下移并渐隐，未提交正文应保留为当前窗口会话草稿。

## 原因与修复

快速输入原生控制器原先没有监听键盘隐藏通知。现监听键盘显示、即将隐藏与隐藏完成通知，仅接受当前窗口、当前屏幕、由该输入 WebView 激活的软键盘。前端再次检查会话及输入归属；其他窗口、普通焦点切换、窗口失焦、尺寸变化和仅外接键盘附加栏不会直接关闭输入框。

键盘隐藏事件带会话标识和一次事件标识，扩展现有 closeQuickComment 请求，在关闭前提交最新正文快照，保留中文组词和 Markdown 模式。原生层校验事件后使用系统动画剩余时长、曲线和经过坐标转换的下移量；缺少参数或减少动态效果时采用短淡出。关闭期间冻结布局，关闭失败恢复可见内容，旧通知不能关闭新窗口，关闭或停用时移除监听。

保存成功继续使用已有退场动画。保存结果待核对时保留提交记录，避免重复追加。草稿不扩展为跨应用重启的长期保存。
