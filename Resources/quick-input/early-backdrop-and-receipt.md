# 快速输入回执修复与提前淡出

日期：2026-10-12。当前工作区未提交、未推送、未发布。

## 提交回执与输入范围

用户报告开启 Markdown 后回车出现评论类型不匹配。原实现把会话和提交记录存入原生控制器的动态对象属性，跨 JavaScriptCore 与原生对象边界可能改变布尔值的表示；严格布尔校验因此存在风险。模拟原生字典布尔转换后，旧实现返回的 Markdown 为 false、persisted 为数值；修复后返回的类型与请求一致，persisted 保持布尔值，相同提交仅追加一次。实际宿主未取得动态属性的原始值，模拟结果不等同于直接观测该转换过程。

会话、草稿与提交记录改为保存于闭包内的 JavaScript 字典。原生控制器只保存字符串会话标识。回执校验、目标固定、失败时正文保留和未知结果禁止重复写入继续保留。

用户确认未提交草稿继续保留，但输入不关联已有评论。新输入不会读取已有评论；保存完成后再次打开为空白。Markdown 最近选择继续由原生配置保存。新增断言覆盖上述边界。

修复包安装后，通过本地 Bridge 只读回读观察到新增评论的 format 为 markdown，并在宿主界面观察到公式渲染。该内容由人工交互产生，验证过程没有写入测试评论或执行撤销；该证据不能替代完整的撤销、重做与失败注入验收。

## 背景提前淡出

背景保持独立覆盖层，采用 ease-in-out 曲线。透明度在退场动画的 78% 时降至零，余下阶段保持透明。定向收缩持续 680 毫秒，背景约在 530 毫秒完成淡出；目标无效及减少动态效果继续使用原有降级路径。保存确认后才播放动画，关闭仍由面板结束事件触发。

生产浏览器的连续采样结果：约 380 毫秒时背景透明度为 0.16；约 540 毫秒时背景完全透明，面板透明度仍约为 0.52，面板继续缩小。桌面、手机和深色平板布局分别记录 43 帧，退场约持续 700 毫秒。暂停动画截图仅用于目视检查，连续性结论来自实际运行采样。

试验性网页滚动容器透明设置已经撤回。自动化点击未稳定打开原生快速输入窗口，尚不能确定窗口加载问题或点击定位偏差；未将该现象认定为原生接口根因。当前最终包继续使用原先的透明容器设置，实际宿主的退场合成与帧率待验收。
