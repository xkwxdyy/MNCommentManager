# MN5 顶栏保护开发者说明

记录日期：2026-10-13。来源：当前聊天中用户转贴的 MarginNote 开发者说明。提交编号为 hg 21156、21171；该说明报告代码已提交，不能据此认定当前安装的宿主已经包含改动。

## 说明原文

> 查到了，这个现象与 MN5 沉浸模板的顶栏保护有关：插件窗口与上胶囊保护区域重叠时，宿主会降低插件视图的不透明度。原先 alpha 上限是 0.25，确实太透明，而且没有说明原因，不能直接归因于插件没适配。
> 目前按短期兼容方案调整，代码已提交：
> 重叠时的 alpha 上限改为 0.6，让插件内容更清楚；插件原本比这个值更透明的，不会被强行调亮。
> 增加提示：「插件窗口遮挡顶部工具栏，请移动或关闭插件窗口。」提示约 3 秒，不拦触摸。同一窗口生命周期内，每个插件最多提示一次；不同插件之间至少间隔 30 秒，已有弹窗或 HUD 时跳过，不反复打扰。
> 移开保护区域后恢复原 alpha；如果插件期间主动调整了 alpha，则恢复它最新设置的值。
> 不采用强制置顶、挪动插件窗口或加 mask 的方案，不改变插件的位置、层级和现有交互逻辑。
> 这个方案仍然会在重叠时让插件半透明，只是减轻程度并解释原因，不是取消保护，也不提供新的点击穿透机制。
> 定向回归测试及 Catalyst SDK 编译检查已通过，覆盖移入 / 移出、恢复原值、提示去重、嵌套视图和多窗口等情况。整包构建此前被 Jinja/PCH 缓存不一致阻塞，尚未完成实际插件的视觉验收。请后续测试包重点复核拖动、键盘、弹窗和暂停 / 恢复场景；这里是代码完成状态，不代表已经上线。
> 相关提交：hg 21156、21171。
