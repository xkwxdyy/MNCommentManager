## 连续操作与中文组词安全复审

审查通过失败测试复现保存刚开始、界面状态尚未渲染时，键盘隐藏或关闭按钮可能提前发出关闭请求。关闭入口现同步检查提交记录与编辑锁，等待组词完成后才取得正文快照；保存结果待核对仍保留原提交记录。结束组词的回车不会触发新增评论，关闭失败保留最终正文。

完整前端测试（228 项）、快速输入专项测试（45 项）和 Node.js 回归脚本（57 个）均通过。原生120轮连续操作恢复80份草稿，40次保存仅产生40条评论，80次提交重放没有额外追加，240个迟到请求被拒绝。最终包内浏览器的组词关闭、关闭失败恢复、回执丢失重试及连续操作通过。
