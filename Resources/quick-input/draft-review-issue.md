## 问题与复现

快速输入新增功能的源码审查发现正文覆盖风险，尚未发布，也未取得真实 MarginNote 设备反馈。

- 已有原生草稿时，网页初始化请求未返回便关闭窗口，旧前端会发送空正文并覆盖原生草稿。
- 草稿写入没有版本号，旧请求迟到时会覆盖较新的正文；关闭快照也可能被后续旧请求覆盖。
- 换行后在 React 尚未提交页面值时立即关闭窗口，读取旧页面值可能丢失刚插入的换行。

上述路径已通过回归测试复现，修复前测试失败。

## 修复

草稿请求增加递增版本号，原生层忽略旧版本。初始化未完成时关闭窗口不发送正文；关闭以同步保存的最新文本作为快照，并冻结后续输入和写入。关闭失败恢复原编辑或待核对状态，保留正文。

草稿继续按已确认方案保留在当前窗口会话内，不扩展为应用重启后的长期保存。
