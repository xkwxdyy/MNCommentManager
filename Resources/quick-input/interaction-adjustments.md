# 快速输入界面调整与验证

日期：2026-10-12。

本轮根据用户截图修复设置动作标签拆行和浮动按钮遮挡，并调整提交后的退场动画。

## 改动

- 设置行采用内容宽度标签列和可收缩的下拉框列，动作标签保持单行。
- 按钮定位转换窗口锚点坐标，纳入原生菜单、MNPinner 附加按钮及嵌套工具栏。整组按钮通过障碍边缘候选位置选择空闲区域，并在其他插件延迟显示后复查。按住按钮期间保持位置，窗口关闭后迟到回调不会恢复按钮；没有可用位置时隐藏整组按钮。
- 定向退场持续 680 毫秒，正文在 240 毫秒内淡出，面板连续移动和缩小，末段降低透明度。无效目标采用 420 毫秒淡出，减少动态效果采用 120 毫秒淡出。
- 面板动画结束后关闭窗口，子元素动画不会提前关闭。关闭期间保留退场样式，超时提供降级关闭。
- 已保存但关闭失败时恢复可见提示和正文，保持提交锁定。关闭重试不追加评论。

## 本轮验证

- 完整前端测试：16 个测试文件、206 项测试通过，其中快速输入测试为 23 项。
- 原生快速输入、浮动按钮和设置命令模拟测试通过；本轮新增坐标转换、原生菜单、延迟附加按钮、整组避让、关闭后迟到回调及拥挤区域降级检查。
- 浏览器设置排版：320、375、600、1024 像素宽度通过，包含深色主题，下拉选择和保存通过模拟接口验证。
- 开发页面和最终生产页面均通过实时逐帧动画检查。生产页面在桌面、手机和深色布局中各记录 43 帧，退场持续约 700 毫秒，位移、缩小和透明度具有持续变化。逐帧记录见 `interaction-review/package/report.json`。
- 快速输入布局覆盖手机、平板、桌面、低高度、深浅主题及减少动态效果。
- 浏览器与原生源码联合模拟通过：未送达重试、成功回执丢失重试、部分写入保存失败后的核对均仅追加一条评论；乱序草稿回写后重开保留最后正文。见 `interaction-review/failures/failure-report.json`。
- 隔离生产构建通过；安装包压缩完整性、25 个 JavaScript 文件语法及构建源码与当前源码一致性检查通过。
