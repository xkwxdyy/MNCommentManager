## 复制与格式刷分离（原型修订）

画刷入口原先执行复制，而更多菜单中的格式刷又进入批量粘贴，导致同名操作具有不同含义。本次原型分开如下流程，正式产品规则仍待操作反馈确认。

- 复制格式：独立复制按钮保存样式快照，不打开目标列表、不改正文，也不产生撤销记录；源评论随后修改或删除不会联动修改该快照。
- 粘贴格式：读取已复制快照，允许跨卡片与多选；普通文字、简单 Markdown 按既定转换规则预览后保存。
- 格式刷：直接读取当前源评论，只列出当前卡片的其他 HTML 评论，排除源评论与非 HTML。应用后退出；取消、应用和撤销均不修改格式剪贴板。
- 编辑、新增和转换分别保存为整次操作。无变化保存不新增撤销记录，取消只丢弃当前草稿，来源与目标的修订变化拒绝旧预览。

图标、入口名称及实际行为已经对应；共享图标包未覆盖的复制、粘贴、撤销保留标准图形。窄屏保留富文本按钮，移动和删除继续通过已有更多操作使用。模型与浅深色／不同尺寸的后台浏览器完整流程通过；新截图和回执位于 `artifacts/rich-text-lifecycle-prototype/checks-v2/`。
