## 已完成的源码修复

HTML 模块标题源正文原先受到 `max-height:20px; overflow:hidden` 限制，实际富文本预览需要更高的行高和内边距。修复后，原生 HTML 标题源按实际内容展开并允许换行；长文预览继续沿用原有展开机制。

格式刷图标已经放在每条 HTML 评论标签旁，可以直接使用对应评论作为源，不要求先选中评论。更多操作入口保留，底栏的重复入口移除。禁用原因、键盘操作与关闭后的焦点返回保留。

格式刷批量写入和整批撤销在事务结束后调用既有宿主刷新方法；失败后的恢复同样触发刷新。刷新逻辑复用 `CommentMutations`，优先调用 `MNUtil.refreshAfterDBChanged`，并保留应用级回退。
