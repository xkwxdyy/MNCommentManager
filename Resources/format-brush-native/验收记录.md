# 原生 HTML 评论格式刷验收

日期：2026-11-15。范围：评论管理器正式接入、Mac 真实评论批量复制、正文与顺序保护、管理器内整批撤销。

## 实现与限制

- 单选具有原生 RTF 的 HTML 评论作为源，点击格式刷图标，列出当前卡片的其他 HTML 评论；支持多选、预览、取消和应用。
- 首版复制统一的字体名称、字号、文字色和背景色。混合字符格式、下划线等额外格式、链接与附件，以及无法保留的评论标识或折叠元数据均明确禁用。
- 业务代码直接调用 `MbBookNote.appendRichTextComment(text, style)`，通过索引映射替换目标位置，并保留字段与标签属性。MNUtils 同名包装不转发样式参数，不能直接替代原生调用。
- 替换前对照新旧 RTF 的正文字符与换行，保护 `text` 字段与实际 RTF 不一致的导入评论；编码变化导致无法确认正文一致时保留原评论。
- 预览绑定完整评论指纹；正文、顺序或元数据变化后拒绝旧预览。管理器撤销同样检查指纹，避免覆盖后续编辑。失败恢复仅处理已确认的追加项和已完成目标，不调用宿主全局撤销历史。
- 整批撤销使用管理器顶部的撤销图标。本次直接调用 `UndoManager.undo()` 后，评论仍与应用后状态一致，未通过原生撤销验证；不承诺系统快捷键撤销结果。
