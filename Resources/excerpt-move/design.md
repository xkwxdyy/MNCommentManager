# 摘录移动前的转换确认

日期：2026-10-18。来源：当前聊天中的最新明确要求。该要求替代此前“完成后告知”的记录。

## 当前行为与范围

- 文本和图片原生摘录的行内移动、包含摘录的选区移动均先显示“移动摘录前需转换卡片”。说明明确告知移动需要转为非摘录版。
- 点击“转换并移动”后才发送原有结构化移动请求，插件层沿用转换、映射校验和移动事务。取消、Escape 或点击遮罩均不转换、不移动。
- “不再提示”在点击确认后通过插件层保存；设置中可以重新开启。保存失败保留确认窗口且不移动，回执丢失时只读回查。
- 关闭确认窗口或切换卡片后，不允许迟到的设置保存回执触发原移动。移动请求发出前关闭确认窗口，避免部分转换后从旧选区重复执行。
- 普通评论移动保持原流程，移动完成后不再弹出转换说明。
- 原生摘录的行内箭头、有效目标限制、转换支持范围、卡片 ID 变化、链接迁移和撤销规则沿用现有实现。
