# 锁定摘录移动的历史实施与验证

日期：2026-10-18。该记录属于“完成后告知”的旧方案。用户最新要求已将该方案替换为移动前确认，当前结果见 [confirmation-validation.md](confirmation-validation.md)。以下内容仅保留历史证据。

## 最终行为

- 文本、图片原生摘录行提供上下箭头。原生摘录固定在顶部，上移禁用；存在下方评论且支持转换时，下移直接转换并移动一位。
- 行内按钮只处理对应摘录，已有选区移动仍处理完整选区。行内移动与选区移动均直接执行，无需转换前确认。
- 只有原生回执明确确认转换及移动全部完成时，页面才显示完成说明。普通评论移动、失败和部分完成不会显示转换成功说明。
- 完成说明提供“不再提示”，点击“知道了”后通过既有设置命令保存。保存失败保留说明并允许重试，不会重复移动；响应丢失时只读回查。
- 评论管理设置增加“移动摘录时显示转换提示”，默认开启。偏好由插件层 NSUserDefaults 保存，键为 `mncommentmanager_show_excerpt_move_notice`，网页未新增业务持久化。
- 沿用现有转换、链接迁移、选区映射及撤销分组。卡片 ID 会变化，说明中明确告知。

## 本轮验证

- 前端完整测试：250 项通过，包含摘录移动专项 17 项；覆盖文本和图片、首次点击、无有效目标、不支持转换、普通移动、完整选区、重复点击、切卡后的迟到响应、关闭提示、重新开启、回执丢失及保存失败。报告见 [frontend-report.json](frontend-report.json)。
- Node 回归：62 个脚本通过。补充单条文本和图片摘录的实际转换映射断言、无效移动不转换断言及原生偏好重新加载断言。原有转换前确认的静态测试已按新行为调整，相关设置生命周期模拟补齐新增状态回调。报告见 [node-report.json](node-report.json)。
- 焦点验证发现：转换完成时，原评论节点会被替换，不能将旧节点作为提示关闭后的焦点目标。当前使用稳定的选区摘要，专项测试已通过。
- 隔离构建、压缩、ZIP 完整性及包内所有 JavaScript 语法检查通过；当前源码目录的 `src/web-dist/` 未被构建修改。
- 最终包内原生模拟通过设置存储、评论移动刷新及转换运行时断言。转换测试执行现有测试中的运行时部分，不把依赖源码排版的静态断言用于压缩代码。见 [packed-native-report.json](packed-native-report.json)。
- 最终包内网页通过浏览器模拟 Bridge 操作，验证首次点击、关闭提示后继续移动及设置恢复提示；实际测得页面宽度为 480 和 750 像素，无横向溢出。浏览器尺寸接口存在与实际 CSS 宽度不一致的情况，不将请求的 375 像素记作已验证尺寸。
- 人工复读新增逻辑及 `git diff --check` 通过。
