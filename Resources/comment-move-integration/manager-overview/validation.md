# 评论管理器拖动总览接入与验收

2026-10-29。用户确认修正后的原型并明确授权正式接入，替代此前仅制作原型的限制。

## 实现

- 完整评论列表右侧新增单条拖动手柄；正文选择与滚动保留，上下箭头和多选操作保留。
- 移动超过阈值后显示全局轨道与可读摘要；总览包含筛选、模块折叠隐藏的评论。首尾可直达，图片显示缩略图，邻近内容展开。摘要窗口按目标位置渲染，长列表限制总览节点数量。
- 手柄与当前评论使用共同中心线；源列表保持挂载，指针捕获放在列表容器。
- 拖动期间只预览。松手调用现有 moveComments，原生侧先校验顺序、内容与折叠修订，完成后回读校验；列表恢复并定位移动项。支持连续撤销，其他编辑导致快照变化后旧撤销失效。
- Escape、指针取消、捕获丢失、多指、失焦、滚动、面板尺寸变化、切卡、刷新、筛选与弹窗切换均终止预览。横向移开后松手取消。
- 额外支持手柄聚焦后空格进入，方向键或 Home/End 定位，回车确认。

## 验证证据

- 项目 ci/commands.json 登记的 212 条命令通过；其中前端 22 个测试文件、341 项测试通过。首次沙盒内完整检查被既有本地 HTTP 测试的监听权限阻止，取得执行权限后完整检查通过。
- 随后浏览器发现隐藏滚动条改变 ResizeObserver 内容宽度，使拖动立即取消。修正为外框尺寸判断；补充面板真正缩放、滚动中断测试，最终拖动与双指选择专项共 38 项通过。原有模块和折叠专项此前通过。
- 正式 React 组件 + 模拟 Bridge 浏览器验证：鼠标跨多条直达末尾、撤销恢复、键盘首尾、图片摘要与窄屏布局。总览手柄与移动评论的中心差为 0。窄屏实际 CSS 布局宽度为 480，沿用既有管理器最小宽度；浏览器尺寸覆盖不等同于 iPhone 真机。
- 测试页面：web/demos/comment-move/manager-integration.html。模拟 Bridge 仅由该页面导入，不进入生产构建。
- 构建在 /tmp 独立目录执行，未写入源码 src/web-dist 或覆盖仓库根目录旧包。压缩后全部 JavaScript 语法检查、原生移动 guard 测试及正式网页标记检查通过；生产包不含模拟 Bridge。
- 0.1.32 测试包 SHA-256：9613b5acf85b5848e0760bd54e0161fb9ad73fe44cbb2f5ccae755e239f77644。
