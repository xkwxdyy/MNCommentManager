## 问题与用户确认

2026-10-29，完整评论管理器的拖动总览原型出现纵向错位：右侧手柄和正在移动的评论不在同一高度。修正后，用户确认交互可用并授权接入完整管理器。

## 根因与修复

原型摘要列表与全局轨道独立计算纵向位置。现改为共用屏幕坐标中心，使用摘要条带位移保持对齐。正式接入时另发现隐藏滚动条改变 ResizeObserver 的内容宽度，导致刚开始拖动立即取消；改为核对面板外框尺寸，并增加回归。

正式列表新增右侧手柄、全局轨道与可读摘要、图片预览、首尾落位、取消和连续撤销。只移动手柄对应的单条评论，正文继续支持选择与滚动。拖动期间不写入，松手复用原生 moveComments；增加顺序、内容和折叠修订校验，拒绝过期快照。切卡、刷新、筛选、弹窗、尺寸变化、失焦、多指和捕获取消均结束预览。
