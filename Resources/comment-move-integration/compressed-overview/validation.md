# 快速移动压缩摘要接入记录

日期：2026-10-19。来源：用户在独立原型交付后明确要求接入。

## 改动

原生快速移动侧栏增加灰色、低透明度的单行摘要。文字和图片采用等高行，图片显示小缩略图；落点前后的评论显示多行摘要和“上方”“下方”标记，插入线及正在移动的评论摘要使用蓝色。

侧栏优先在空白区域增加可用高度，继续避让卡片和其他控件。压缩列表随目标位置自动滚动，视图数量仅与可见高度有关；5000 条评论的模拟中，目标切换没有增加原生视图，也没有解码全部图片。点按、长按、等距拖动、取消、撤回及松手单次提交沿用原有逻辑。

调整侧栏高度时，上下箭头仍保持原来的宿主坐标，结束预览后恢复正常布局。极端空间不足时仍会采用原有窄栏预览，无法保证同时显示其他评论的可读摘要。
