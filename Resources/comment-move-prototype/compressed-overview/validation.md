# 快速移动压缩列表原型

日期：2026-10-19。状态：独立原型已生成；用户随后明确授权接入，原生实现和测试包见[接入记录](../../comment-move-integration/compressed-overview/validation.md)。下文保留原型阶段的验证结果。

## 交互与产物

其他评论使用等高的灰色单行摘要，图片统一显示缩略图；落点上方、下方评论展开显示。长列表可以滚动，拖动期间压缩列表自动跟随目标位置。左侧卡片保留评论的不同高度，演示提供第三条为图片的短列表、混合评论和长列表。

点按卡片中的评论可以更换移动对象。侧边手柄支持拖动，箭头支持点按及长按，撤回恢复整段移动。横向移开、Escape、窗口失焦、布局变化和指针取消可以终止预览。窄屏采用上下排列，仅用于演示可读性，不代表原生侧栏布局。

- [离线原型](preview.html)：包含样式、脚本和图片，不需要预览服务，不保存业务数据。
- 源码位于 `web/demos/comment-move/overview.html`、`overview.jsx` 和 `overview.css`，原有原型入口未修改。
- 重建命令为 `node web/demos/comment-move/build-overview.mjs`。
- 模拟检查命令为 `node web/demos/comment-move/test-overview.mjs`。
- 本机预览服务可用后，页面地址为 `http://127.0.0.1:5186/overview.html`。

## 本次验证与边界

Vite 独立构建通过。共享手势和顺序模型通过 20 项测试；成品页面的 jsdom 模拟检查通过，结果见 [checks.json](checks.json)。检查覆盖摘要与缩略图、相邻内容展开、预览不改顺序、松手单次落位、整段撤回、横向取消、Escape 中断、长列表末尾、长按及键盘操作。模拟使用合成指针事件和固定几何，不证明实际布局、自动滚动视觉效果或触摸体验。

源码已重新阅读。原生实现、主面板和 MarginNote 安装未修改。
