日期：2026-10-18。范围：评论管理器按钮到 Bridge 命令、定向编辑校验及相关原生操作的调用链。

## 检查结果

| 按钮或操作 | 请求中的目标含义 | 检查结论 |
| --- | --- | --- |
| 普通链接、Markdown 正文及解析结果定位、查看模块提取结果 | 链接或新建子卡片 | 共用 focusLinkedNote；前轮修复已覆盖，允许导航且保持编辑目标 |

| 批量预览、执行与读取批量状态 | 原生多选上下文 | 定向单卡会话中限制批量操作符合原设计；原生打开批量面板会清除定向单卡会话 |
| 原生单卡工作流与快速输入入口 | 独立菜单上下文或快速输入会话 | 使用各自已有的上下文校验；快速输入通过独立控制器执行 |

## 新发现与修复

通过 Pinner 打开定向编辑器后，共用转换函数会创建替代卡片，前端接收替代卡片快照，但定向会话仍保存原卡片标识。因此，随后编辑、复制或移动新卡片时会被判为过期；刷新则读回已被合并的原卡片。

修复在共用转换函数完成新卡片校验后调用 ExternalCardEditor.replaceTarget，只更新仍指向原卡片的已注册编辑会话。请求标识与其他会话字段保留。转换后续步骤中止时，已完成的转换仍更新编辑目标；转换前预检失败时不切换目标。导航、普通写入与批量限制继续保留。

## 本轮验证

- 新回归在修复前复现移动摘录后会话仍保留原卡片标识；修复后，生产命令与转换函数联合模拟覆盖移动、删除、合并、合并到摘录及提取并删除原内容。
- 转换后刷新、复制与新目标写入校验通过，旧目标写入被阻挡；转换后中止、预检拒绝、无关会话与关闭会话检查通过。
- 定向编辑生命周期、链接导航、Bridge 生命周期、评论移动刷新、评论编辑刷新、工作流执行、运行时依赖隔离、普通链接及 Markdown 链接键盘回归通过。
- 压缩包内及实际安装目录中的生产脚本均通过转换和导航回归。专项脚本接受生产资源目录参数；其中原生按钮入口的源码文本检查继续针对工作目录源码，运行时转换、数据读取、定向会话与 Bridge 命令来自指定生产目录。
- 测试包 ZIP、全部 JavaScript 语法及差异空白检查通过。修改后的源码已人工复读。
