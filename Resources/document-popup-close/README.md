# 文档摘录按钮显隐修复

日期：2026-11-08。关联：[Issue #111](https://github.com/xkwxdyy/MNCommentManager/issues/111)。

文档视图关闭摘录菜单时，评论管理器此前未监听 `ClosePopupMenuOnSelection`，导致浮动按钮无法进入既有清理流程。现已补齐监听与场景断开时的注销，继续复用延迟隐藏、按压保护、会话代次和目标卡片校验。

本机连续点选又发现新按钮被 `native-menu.context-changed` 误清理。普通文档菜单没有接入评论管理器原生命令时，不应由原生入口的选区校验关闭独立浮动按钮。现增加原生命令存在性判断，同时保留已接入菜单的根证据、目标与场景校验、原生长按和清理行为。

源码及包内回归覆盖关闭通知分发、场景注销、旧卡片回调、新会话重开、按压保护、普通菜单保留动态入口，以及已接入原生命令时的失效保护。新增普通文档菜单回归在旧源码失败，修复后通过。

Mac MarginNote 5.1.0 build 51004 已实际执行摘录 A→B→A→B→A→B 连续点选，按钮持续正常显示。关闭菜单后约 350 毫秒与 1.35 秒、重新打开后再次关闭的实际截图均未见残留。原阅读状态全部字段及摘录清单、原文、元数据已回读核对一致。

已验收测试包版本为 0.1.39，SHA-256 为 `6ff7eac07152231f612ffbbaebc93635ed472eae60c199605be30027fa74f274`；0.1.40 在该修复上更新版本及发布日志，不据此新增未执行的设备验收。iPad、iPhone、长按、分屏及其他宿主版本仍待验收，Issue 保持开放。

原始截图、诊断日志、安装备份入口及机器回执保存在本地 `Resources/document-popup-close/native-test/`，不纳入本次 Git 提交。对应验收回执为 `accepted-native-report.json`，发布记录另存于 `Resources/releases/v0.1.40.md`。
