# 工作流易用性与生命周期优化

工作流是保存好的评论处理动作或动作组合。当前界面优先展示操作摘要和菜单位置，名称、执行步骤、高级筛选及管理操作按需展开。菜单位置需要保存后才会生效，排序会立即保存；保存配置不会运行评论操作。

## 设置与使用

1. 首次打开：选择左侧的操作，设置单选卡片或多选卡片时的显示位置。名称和执行步骤默认收起，使用次数位于管理操作区。此流程已通过模拟交互验证。
2. 设置菜单：选择“直接显示在菜单中”“放入工作流子菜单”或“不在菜单中显示”，再点击“保存”。隐藏的工作流仍保留在列表中，可以重新显示。单选和多选分别保存菜单顺序。此流程已通过保存、重开和回读模拟验证。
3. 编辑执行内容：展开“编辑名称与执行步骤”，再修改名称、可执行场景和动作。新建工作流会根据首个动作生成名称；手动填写的名称会保留。评论筛选和操作参数按需展开；仅含筛选条件的工作流不能保存或运行。此流程已通过模拟验证。
4. 保存与关闭：未保存的修改会受到关闭确认保护。收起编辑区会保留草稿；保存结果缺失或不一致时不会显示成功。键盘导航包含展开入口，并跳过收起区域中的控件。此流程已通过异常回执、焦点和关闭回归验证。
5. 复制与恢复：复制采用已保存的内容，原工作流保留。恢复默认配置会明确显示目标工作流和影响范围，先载入草稿，再由保存操作生效。已恢复的配置不需要重复保存。此流程已通过模拟验证。
6. 运行与中断：原生菜单中的管理入口直接请求打开工作流设置，页面加载和其他编辑窗口结束后再处理请求。已打开的工作流草稿不会被覆盖，关闭面板会取消待处理请求。工作流执行中断后会提示检查结果，必要时撤销后再运行。入口生命周期和执行器已通过模拟验证。
