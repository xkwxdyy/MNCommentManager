## 完成范围

本轮覆盖 `web/` 中维护的全部 HTML 入口，以及实际生成界面的 React 组件和样式：正式评论管理器、快速输入、模块演示、卡片旁移动演示、压缩列表、管理器模拟验收和独立拖动总览。`src/WebPanelController.js` 的内嵌加载失败页也已调整。生成目录与历史产物不作为人工编辑对象。

- 公共颜色、字体、形状和触摸尺寸集中到 `web/src/theme.css`，由正式管理器、快速输入及相关演示复用。
- 提高必要辅助文字、类型标签和计数的对比度；区分文字颜色与明亮指示色，补充可读的实色操作表面。
- 顶栏的刷新、工作流、设置和关闭采用图标，保留操作名称、悬停提示与忙碌状态。
- 窄屏评论卡片使用单列内容网格，模块演示正文不再被排入 18 像素宽的列。
- 整理模块演示的内边距与复选框命中区域；低高度窗口采用单行可滚动底栏，并收起默认手势说明。实际状态和错误信息仍可显示。
- 快速输入、下拉框、帮助面板、模块和移动预览沿用统一的文字与表面规则。独立拖动总览原型保留绿色配色。
- 加载失败页支持深浅主题、长错误换行和错误文本的原样显示。

设计规范已新增至项目根目录 `DESIGN.md`。已确认方向与具体实现推断分别标注。现有草稿、原生存储、评论事务、撤销和拖动协议继续沿用；本轮没有添加动效。
