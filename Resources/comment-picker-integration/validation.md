# 评论选择器与滑轨整合验证

日期：2026-10-18。来源：用户明确要求修复审查问题、整合定制功能并验证。该授权替代此前仅分析的阶段范围，不包含提交、推送或发布。

## 实现

- `src/CommentMoveController.js` 独立实现原生评论列表、滑轨与移动校验。列表打开、选择评论及最终提交均读取最新卡片；评论顺序、内容或原生版本变化时拒绝旧操作并刷新列表。移动后回读顺序，原生静默失败不能显示成功。
- `src/DynamicCommentActions.js` 增加移动图标，卡片至少有两条评论时显示；布局只读取评论数量，不生成完整媒体快照。管理、添加及工作流原有行为保留。
- `src/MNCommentManagerAddon.js` 注册 selector，统一异常反馈；笔记本关闭、卡片切换、按钮停用和场景断开清理面板。窗口尺寸变化时关闭旧面板，避免继续使用过期坐标。
- 面板宽度限制为宿主可用宽度与 360 中的较小值，内部控件随实际宽度调整。宿主空间不足时明确拒绝打开。
- `src/main.js` 仅增加模块导入。网页设置说明、README 与未发布日志已同步。没有移入定制包内的旧备用清单或未使用的移动入口。

评论签名使用原生快照版本和按顺序排列的评论内容、媒体标识及合并卡片标识；界面预览的临时状态不参与签名。卡片会话和面板会话分别校验，旧控件和旧手势不能作用于重新打开的面板。

## 宿主安装与设备边界

最新状态（2026-10-18）：用户要求先重新设计面向 iOS 的独立快速移动交互，原有主面板保留。数字滑轨方案的安装与正式接入推进已暂停，测试包未安装。当前原型与验证见 [交互草案](../comment-move-prototype/design.md)及[原型验证](../comment-move-prototype/validation.md)。以下安装冲突说明为此前阶段记录，不代表当前安装安排。

安装前核对发现，聊天“修复卡片链接定位请求过期”正在同一应用中验收，并安装了 `WebClickResumeProbe.js` 临时模块。该聊天已取得暂停其他宿主操作的确认。本轮因此尚未安装或操作界面，避免覆盖临时模块及中断连续撤销重做验收。

本轮安装脚本 `install-test-package.py` 会拒绝覆盖含 Probe 或 Diagnostic 的安装，之后使用完整包、先备份、正常退出、原子替换并逐文件校验，最后正常启动。正常退出失败或安装资源发生并行变化时保留原安装。

iPad 动态按钮不显示仍由 Issue #67 跟踪；共享布局规则本轮没有修改。iPad、iPhone、多窗口命中测试、实际手势与真实数据库撤销重做尚未验收。
