# HTML 下拉框与折叠状态校验验证

2026-10-11，用户要求采用与面板一致的 HTML 下拉框，并反馈 iPad 的评论折叠入口消失和状态错误。随后 macOS 出现相同现象，排查按跨平台回归处理。iPad 宿主为 MarginNote TestFlight 4.5.0 build 60。

## 改动

正式面板的模块设置、正文移动、工作流配置和多卡片编辑统一使用 `HtmlSelect`。控件包含选中标记、方向键选择、首尾定位、键盘确认、取消、外部触摸关闭和焦点恢复，使用原有颜色变量与至少 44 像素的触摸区域。选项列表根据弹窗可见空间向上或向下展开。模块设置的复选框与说明恢复同行显示。

折叠适配器停止强制校验索引操作未使用的 `ownerNoteId` 和 `commentId`。卡片身份、版本、连续索引、布尔状态和保存回执仍须通过校验。异常状态现在显示字段路径；诊断仅包含路径与类型，不记录正文。该改动不会生成历史标识、直接写入批注元数据或自动重试。

## 证据

本机 MarginNote Bridge 0.92 的只读接口确认截图对应卡片提供有效卡片身份、版本、索引和布尔状态；部分历史评论的稳定标识为 JSON null。该检查没有修改卡片。HTTP JSON 的空值不证明原生 JavaScriptCore 中的具体空值表示，真实插件验收仍须保留。

前端完整测试 163 项通过。新增 HTML 控件测试覆盖选择、键盘、取消、外部触摸、禁用和焦点；模块及工作流测试通过真实 HTML 选项操作验证保存行为。后续键盘事件隔离的控件专项测试再次通过。

原生折叠测试通过，覆盖缺失未使用标识、模拟原生空值对象、入口能力、索引写入，以及必需字段异常时拒绝写入并提供诊断。现有保存、冲突、引用卡和工作流模拟测试继续通过。

Node 检查共 53 个脚本通过。首次执行发现 Bridge 生命周期测试的命令分类清单未同步模块命令；生产分类已存在，测试清单已补齐，失败检查重新执行通过。

普通网页构建、Safari 11 目标 IIFE 构建和隔离副本完整安装包构建通过，ZIP 完整性、入口资源及版本核验通过。仓库 `src/web-dist/` 未修改。最终包内网页通过 985×800 桌面、768×700 触屏、375×480 深色触屏和 320×360 触屏检查，覆盖选项菜单边界、选择、键盘取消、配置保存、评论折叠和焦点恢复，页面没有脚本错误。浏览器使用模拟 Bridge，未验证真实原生写入。

浏览器检查脚本为 `scripts/check-html-select-panel.mjs`，结果和截图保存在 `dist/html-select-checks/`。
