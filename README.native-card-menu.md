# MN5 场景模板接入原生卡片菜单

本文对应包含原生卡片菜单功能的源码构建。MN5 仍处于内测阶段，该接入方式可由场景模板使用者选择；现有动态入口继续保留。当前实际验收范围为 MN5 的 Mac 卡片菜单，旧宿主、iPad、iPhone 和文档摘录菜单仍待验收。

## 使用前提

先安装并启用 MN Utils，再安装包含该功能的 MN Comment Manager 构建包。场景模板只保存入口和场景设置，不能代替插件安装。插件版本号保持不变期间，既有同版本安装包不一定包含当前源码中的功能。

全局启用插件后，还须允许插件在当前场景内运行。仅启用全局插件而未配置场景许可时，场景中不会出现该插件的原生或动态入口。

## 从新模板开始

1. 在 MN5 中导入 `.mntemplate` 场景模板。宿主导入器接受根目录包含 `template.json` 的压缩包；内部模板 JSON 不能直接作为模板包导入。
2. 打开场景模板菜单，选择“编辑场景模板…”，搜索“插件”，进入“允许在场景界面中使用”。
3. 先允许 MN Utils，再允许 MN Comment Manager。仅使用卡片入口时，工具栏放置提示可以选择“暂不添加”；插件在场景内的运行许可仍然有效。
4. 打开卡片的原生菜单，选择“更多 → 自定义…”，在列表下方按需将“评论管理”“添加评论”加入主菜单，完成保存。场景可以只加入其中一个入口，也可以均不加入。
5. 关闭并重新打开卡片菜单，检查入口及动态按钮。默认启用“自动隐藏重复动态入口”，无需额外调整插件设置。

已经包含插件许可和原生命令的模板，导入后可以直接使用；前提仍为 MN Utils 和对应 CommentManager 构建已经安装并启用。通用模板缺少插件许可或原生命令时，需要补充相应设置。

菜单自定义会保存到当前模板，使用同一模板的学习集也会受到影响。需要保留原模板时，先在场景模板管理中复制模板，再修改副本。

## 原生入口操作

| 入口 | 单击 | 双击 | 长按 |
|---|---|---|---|
| 评论管理 | 卡片旁的快捷面板；空卡直接打开完整面板 | 完整评论管理面板 | 整卡操作菜单 |
| 添加评论 | 快速输入 | 无独立动作 | 无独立动作 |

快捷面板复用评论选择、排序、复制、提取和折叠功能。整卡操作菜单直接列出“快捷面板”“完整面板”“添加评论”及既有整卡操作。滑动与拖动继续用于快捷面板内的评论操作，原生按钮不增加对应动作。

快速输入沿用最近输入模式及防重复打开机制。同一运行期间，未提交草稿可以在关闭重开或切换场景后恢复；草稿保存在当前窗口会话中，重启应用后不保留。切换到另一张卡片时，已有输入框需要先关闭，避免将内容提交到错误目标。

## 与动态入口配合

默认配置下，已确认当前主菜单有效时，动态入口显示如下。

| 原生主菜单接入情况 | 保留的动态入口 |
|---|---|
| 均未加入 | 评论管理、下拉菜单、添加评论、评论整理 |
| 仅添加评论 | 评论管理、下拉菜单、评论整理 |
| 仅评论管理 | 评论管理、下拉菜单、添加评论 |
| 均已加入 | 评论管理、下拉菜单 |

动态“评论管理”和下拉菜单仍提供直接访问完整面板及整卡操作的方式；当前宿主接口不足以确认附加手势的键盘和 VoiceOver 可达性，因此默认继续保留上述入口。

插件设置中的“自动隐藏重复动态入口”只控制当前显示结果，不改写原动态按钮开关、顺序或手势配置。关闭该设置可保留原有动态入口。自定义点按或长按动作继续保留对应按钮，包括将长按设为“不执行动作”的情况。

关闭动态入口总开关后，已接入的原生命令仍可使用；重新打开总开关时，原显示顺序和动作设置继续有效。仅关闭某个动态按钮，也不会因场景切换而自动重新启用。

移除原生命令后，相应动态入口会在新菜单中恢复。场景内停用插件后，该插件的原生和动态入口均停止；重新允许插件后，需要重新打开卡片菜单。切卡、切学习集、切窗口或切场景后，旧菜单动作可能被拒绝，关闭并重新打开菜单即可建立当前目标。

仅将命令放在“更多”中、按钮被遮挡、模板采用尚未识别的菜单布局，或宿主未及时提供有效主菜单时，插件继续保留动态入口。首次打开仍显示重复入口时，可以关闭并重开菜单；该处理优先保证功能仍可访问。

## 模板编写参考

模板作者可以在原模板中合并以下配置片段，并保留原模板标识、名称、工具栏及其他设置。

```json
{
  "plugins": [
    "marginnote.extension.mnutils",
    "marginnote.extension.mncommentmanager"
  ],
  "selectionMenu": {
    "cards": [
      "commentNote",
      "addon.marginnote.extension.mncommentmanager.nativeCommentManager:",
      "addon.marginnote.extension.mncommentmanager.nativeAddComment:"
    ]
  }
}
```

该片段不是完整模板包。已有 `plugins` 或 `selectionMenu.cards` 配置时，应合并所需条目，保留原有插件和菜单项，并避免重复命令。宿主菜单编辑器可能同时保存 `commentNote` 和 `noteHighlight:`，当前实现已兼容该实际结构。其他菜单项或继承配置可能无法确认自动去重，原生命令仍可使用，动态入口保留。

完成模板配置后，优先通过宿主“导出场景模板”生成 `.mntemplate`，再在独立测试模板中验证导入。分发模板前，应检查模板包是否附带插件代码；本功能不要求模板包附带插件代码。

## 验收与限制

新模板验收应覆盖：导入及插件许可、部分与全部接入、移除入口、停用恢复、场景切换、单击双击长按互斥、输入取消及重开、应用正常退出及重启。重启后应保留模板和入口设置；未提交草稿按上述窗口会话规则处理。

Mac 的实际测试记录见[新模板生命周期验收](Resources/native-card-menu/adaptive-entry-test/fresh-lifecycle-20261022/validation.md)。其他设备及辅助功能的待验收状态不能由源码或压缩包回放代替。
