# 决策点

- 2026-10-19｜用户在压缩列表原型交付后明确要求“接入吧”，授权接入原生快速移动侧栏，替代此前仅制作原型、等待接入确认的阶段安排。沿用既有测试安装授权；正式发布和推送未获授权。

- 2026-10-19｜用户要求快速移动时显示其他评论的灰色低透明度压缩内容，并明确先制作原型查看效果。当时阶段仅制作独立交互原型，保留既有原型入口；原生接入与安装等待后续确认的安排已由后续“接入吧”授权替代。该需求扩展此前仅显示落点前后内容的预览范围。

- 2026-10-19｜用户要求快速移动轨道均匀、鼠标拖动跟手，并明确指出上下文被压缩到无法辨认。当前修复采用整段等距坐标、原位更新手柄及可读摘要区域，保留侧栏显示、卡片避障和主面板原有逻辑；该要求替代分段映射、逐帧重建及八字窄摘要的做法。

- 2026-10-18｜用户明确要求移动后的信息保留在卡片侧栏内，避免遮挡卡片正文。该要求替代独立结果浮窗：位置标记、撤回及目标摘要均归入侧栏，展开区域同样避障；空间不足时采用紧凑显示，主面板原有逻辑保留。

- 2026-10-18｜用户明确反馈快速移动持续误报没有空间，要求自动避障。侧栏应根据真实卡片视图和周围控件寻找左右或上下可用位置，展开轨道同样避障，不将定位失败统一当作空间不足；普通快速移动不依赖手动调整卡片。该要求适用于本轮侧边集成，主面板原有逻辑保留。

- 2026-10-18｜用户已认可拖动跨条与长按连续定位方案，明确授权整合项目并验证，主面板原有逻辑保留。该授权替代此前正式接入与安装暂停的安排；使用原生卡片侧边控件，选择评论入口按内容展示列表，移动过程中只预览前后内容，松手后调用既有移动接口一次。原生宿主未提供已核实的评论点击索引接口，因此不模拟点击卡片内部评论。
